# Distribution plan

## Search surfaces

- GitHub description and topics: coding agents, agent testing, file integrity, encoding, line endings, CRLF, BOM, and developer tools.
- Python package metadata: `agent-file-integrity-litmus`, with the same exact problem terms and supported Python versions.
- README sections for coding-agent file corruption, Windows-1252 transcoding, CRLF preservation, UTF-8 BOM preservation, final-newline drift, executable-bit drift, and stale-write detection.
- Accurate release title and notes that name the six byte/mode fixtures and the Codex/opencode adapter boundary.

## Concrete channels

- GitHub repository and release search.
- Relevant coding-agent client issue discussions only when the saved fixture reproduces that issue and the comment adds actionable evidence.
- Python packaging/search surfaces after package publication is separately justified.
- Developer-tool communities through a technical benchmark write-up; no adoption or user claims until observed.

No outreach will imply maintainer endorsement, users, adoption, or traction that has not been observed.
